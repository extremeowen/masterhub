💡 Повна автоматизація: від комміту розробника до оновлення Pod-ів у кластері без ручного збирання на сервері.

🚀 Повний життєвий цикл HTTP-запиту

1. Клієнт HTTPS запит на api.masterhub.ua/orders
2. DNS Резолвінг домену в IP балансувальника
3. Ingress Перевірка Host/Path, проксі на Service
4. Service ClusterIP round-robin між Pod-ами
5. Pod API Express-контролер і бізнес-логіка замовлень
6. PostgreSQL Збереження у БД через masterhub-db-svc:5432
